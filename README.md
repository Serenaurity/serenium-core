# Serenium Core

AI OS แบบ desktop app — หน้าหลักเป็น **World Network** ทรงกลมที่ประกอบขึ้นจากข้อมูลจริงในระบบ
ล้อมด้วยสนามอนุภาค ล้อมด้วยวงแหวน Session และ Artifact ล่าสุด และมี widget ที่จัดวางเองได้อยู่รอบนอก

กดเข้าไปในทรงกลม → กล้องบินทะลุเปลือก → เข้าสู่ **Knowledge Graph** ของทั้งระบบ

เป้าหมายระยะยาวคือรองรับ AI หลายเจ้า ไม่ใช่แค่ Claude

## สถาปัตยกรรมโดยย่อ

```
core/    Node ล้วน ไม่รู้จัก UI — อ่านไฟล์ แปลง คำนวณ เฝ้าดู
shell/   Electron — วาดภาพอย่างเดียว กินข้อมูลจาก core
```

`core` ห้าม import อะไรจาก `shell` เพราะตรรกะ "อ่านสถานะ agent หลายตัวแล้วตัดสินใจส่งงานไปไหน"
คือหัวใจของ AI OS มันต้องไม่อยู่ในโค้ดวาดภาพ

## ข้อมูล

โค้ดอยู่ที่ repo นี้ **ข้อมูลอยู่ที่ `~/.claude/serenium/`** แยกกันโดยตั้งใจ

รวมถึง `rollup.mjs` ที่ทำงานอยู่แล้ว — เก็บ snapshot การใช้งานรายวันก่อนที่
retention sweep ของ Claude Code จะลบต้นฉบับทิ้ง จะย้ายเข้า `core/` ตอนเฟส 1

ตอนนี้ถูกสั่งโดย SessionStart hook (`rollup-hook.mjs` หน่วงให้รันวันละครั้ง ยิงแบบ
detached ไม่ถ่วงการเปิด session) **เป็นของชั่วคราว** — พอเฟส 2 เสร็จ ตัวแอปจะ autostart
ลง tray แล้วรับช่วงไป `rollup.mjs` ยังต้องรันเดี่ยวได้เสมอ คนสั่งเปลี่ยนได้ ตรรกะไม่ต้องแตะ
